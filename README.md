# **🛒 Olist Brazilian E-Commerce Analytics Dashboard 📊**
### **Welcome to the Olist Brazilian E-Commerce Analytics project! This repository contains a comprehensive multi-page Power BI dashboard built using the public Brazilian e-commerce dataset by Olist. 🚀** 
## **📑 Project Overview & Pages**
The dashboard is structured into three main analytical pages to provide deep business insights:
## **👥 Customer Overview:**
Analyzes customer demographics and distribution across various states and cities. 🗺️
Highlights key customer base metrics and geographical purchasing patterns. 📈
## **💳 Order & Payment Analytics:**
Explores preferred payment methods (such as credit cards, boleto, voucher, etc.). 💳  
Visualizes payment values, installment trends, and revenue distribution using interactive charts. 📊
## **📦 Order Performance Analytics:**
Tracks order fulfillment lifecycle and delivery statuses (delivered, shipped, processing, etc.). 📦  
Identifies key operational trends to evaluate customer satisfaction and delivery efficiency. ✨
## **🛠️ Tools & Technologies Used
## **Power BI Desktop:**
For data modeling, DAX measures, and interactive data visualization. 💻
Excel / CSV Datasets: Olist public e-commerce datasets (Customers, Orders, Payments, Items, etc.). 📂  
## **💡 Key Insights:**
## **Top Payment Method:** 
Credit cards emerge as the most frequent and highest-value payment option among customers. 💳  
## **Fulfillment Reliability:** 
A significant majority of orders successfully reach the delivered status, indicating a stable logistics backbone. ✅
